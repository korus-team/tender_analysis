# Реестры крупных компаний

`russian_companies_mega_registry_with_it.txt` — дополнительный пользовательский
список названий. Он применяется только как последний уровень проверки и только
при точном совпадении названия после удаления кавычек и организационно-правовой
формы. Нечёткий поиск по этому файлу намеренно не используется.

`verified_large_companies.csv` создаётся автоматически при успешной проверке
через ГИР БО ФНС и содержит `inn,revenue,year,name`. Файл локальный и исключён
из Git, чтобы рабочая программа могла безопасно пополнять его без постоянных
изменений репозитория. Основной 30-дневный кэш также хранится в SQLite.
